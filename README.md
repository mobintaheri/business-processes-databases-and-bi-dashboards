# Designing Business Processes, Databases, and BI Dashboards

Course project for Management Information Systems, supervised by Dr. Hadi Mosadegh at Amirkabir University of Technology.

The project followed a supplied business scenario through process modeling, relational database design, and dashboard development.

1. **Process modeling.** Documented the supplied workflows using Visual Paradigm and Visio.
2. **Database and queries.** Mapped data from Excel to SQL Server tables, designed the entity relationships, and wrote eight analytical SQL queries.
3. **Reporting.** Built Power BI reports and dashboards from the course data.

The work demonstrates a course workflow from process diagrams to analytical reporting. The original data, process materials, query outputs, and dashboard files require review before public release.
